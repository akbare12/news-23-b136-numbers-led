## Run

```sh
python3 draw.py            # renders entry.png (1024x1024)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # copies entry.png to out/entry.png
```

`main.py` is stdlib-only and verifies the PNG before copying. `draw.py` uses Pillow.
